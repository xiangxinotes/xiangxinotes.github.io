## 你是梦想家吗？

Ali Abdaal 在视频里，把人分成四类：
- **流浪者（Drifters）**，随波逐流，没志向，没行动
- **梦想家（Dreamers）**，有志向，没行动
- **仓鼠人（Hamsters）**，没志向，有行动
- **大师（Masters）**，有志向，有行动

所以，梦想家 = **有目标、有想法、有理想，但一直原地踏步的人**。

梦想家们好像总爱在脑子里想一想，就满足了，有点像电影《白日梦想家》的主角。

我自己并不能从 “只做计划不行动” 里获得真正的满足。

做计划会带来一定的满足感，但如果我一直不行动，那么做计划的时候有多开心，没行动的时候看到这个计划就有多恼怒。

看到这里，你可以问问自己：“你是梦想家么？” “你是怎样的梦想家？”

## 梦想家行动指南

下面这套流程，方法论来自 Ali Abdaal 的视频，我把它拆成一步一步能照着做的SOP。

我用它梳理了自己的四大目标，我发现自己分析之后变得非常有行动力。

因为我终于分清：哪些我是**真的想要**，哪些只是**人云亦云**。

同时，我也大胆删掉了很多不适合自己的事项，整个人轻松了一大截。

因为我感觉很好，所以把它分享给你，希望在我走向“大师”的路上也能看到你的身影。

### 第一步：找出待办清单

翻出你做过的所有待办清单。

找不到全部的待办清单也没事，先把能找到的一两个拿在手里。

### 第二步：合并同类项，事项划分

把所有事项，按主题归纳成几个方向。

整理期间，合并类似的事项，合并类似的方向。

方向必须是动词，比如减肥、做自媒体、学钢琴。

### 第三步：针对每一个方向，一步步深度分析

拿一张空白 A4 纸，或在电脑上新建文档。

对**每一个方向**，执行以下8步。

#### ① 写下过去的目标

```
过去我以为想要【这里填入你的方向名称】
```

#### ② 写下你自以为的理由

问自己：

**“我为什么觉得自己想要【这里填入你的方向名称】？”**

把能想到的理由全部写下来，分成两类：
- **逻辑**理由 1～N（理性上的理由）
- **情绪**理由 1～N（内心真实的感受）

#### ③ 根据理由判断：你是真的想要吗？

根据上一步写下的理由，做出判断：

- 如果**只有逻辑理由，完全没有情绪理由**：
  - → 你其实**根本不想要**，只是觉得“应该要”。
  - → 建议你**把这个方向从计划里删掉**。
- 如果**有情绪理由**：
  - → 你确实**想要**。

对于你删掉的方向，跳过④～⑦，直接到[⑧ 誊写结论]({{ page.url }}/#-誊写结论)，把它记录下来。

对于你想要的方向，继续下一步。

#### ④ 写下所有真实障碍

把**阻碍你行动的理由**全部写出来。

可以是现实问题，也可以是情绪、恐惧、完美主义。

重点：**一定要写真实障碍，不要骗自己。**

真假障碍举例：
- 假障碍：没有好看的背景，没法做室内自媒体
- 真障碍：我怕背景不够完美，不敢做室内自媒体

#### ⑤ 逐个分析障碍：哪些在你掌控中？

对上一步写下的每一个障碍，逐个问自己：**这件事，在我的掌控范围内吗？**

只有三种答案：
- 不在我的掌控中
- 部分在我的掌控中
- 完全在我的掌控中

- 如果**完全不在掌控**：
  - → 是现实硬限制，且无法改变
  - → 如果它导致目标彻底无法实现，果断把这个方向**删掉**，直接跳到[第 ⑧ 步誊写结论]({{ page.url }}/#-誊写结论)（选模板B）；如果只是堵死了一条路，就换个路径，继续看下一个障碍。
- 如果**部分在掌控**：
  - → 忽略不能控制的部分，只做你能控制的事。
- 如果**在掌控**：
  - → 直接解决障碍，干就完了。

#### ⑥ 制定具体、可落地的目标

把方向变成**可衡量**的目标：

```
我想要【这里填入你的方向名称】达到【可衡量 / 数字 / 状态】的程度。
```

#### ⑦ 拨出具体时间

不给目标安排时间，它永远只会停留在纸上。

所以你必须找一块完全不被打扰，能做这件事的时间。频率你自己定，比如：
- 每天晚上9点
- 每周六上午7-12点
- 每个月15日的下午3-4点

#### ⑧ 誊写结论

到这一步，分析已经结束：要么**继续做**，要么**放下它**。

请把你的结论誊写一遍，保存下来。

人是很健忘的，今天决定了不做。但两三个月之后，可能会问自己“诶，那个事我怎么还没做”。这时候如果你能拿出此时的判断，那你看一眼就知道：“我分析过了，我不是还没做，我是决定放下它了。”

下面提供两个模板，帮你把已经完成的判断变为可回看的文字：
- 判定为**“真想要且能推进”**的方向，请用**模板A**。
- 判定为**“决定放下”**（不管是自己不想要，还是现实做不到）的方向，请用**模板B**。

## FAQ

### 某个方向我舍不得删，但又想不出情绪理由，怎么办？

建议你和 AI 聊聊，让它帮你挖一挖内心真实动机。

如果还是找不到，**把它删掉**！不要觉得可惜，现在时机不对，你根本就不想做这件事。等以后有真正的动力了，再考虑这件事吧。

### 方向下的具体事项如何处理？

按照第三步逐个分析方向之后，你需要根据方向的判定结果，决定具体事项的去留：

- 如果这个方向你其实根本不想要，直接删掉下面所有的具体事项。
- 如果这个方向你舍不得删，但时机不对现在不做，那就把下面所有的具体事项封存起来，以后有动机做了，再来看。
- 如果这个方向你确定想要，那么针对方向下的每一个具体事项，逐一执行 ④ 找障碍～⑦ 安排时间。

## 举两个我自己的例子

下面的例子，是我用这套SOP对自己的两个具体事项进行的分析，供你参考：

### 我真的想要，继续做

过去我以为想要*【学习与人良好沟通】*

- 逻辑理由：因为与人沟通良好可以让我交到新的朋友
- 逻辑理由：因为与人沟通良好可以让我和客户沟通更顺畅
- 情绪理由：因为不会与人沟通给我带来了不好的体验，我再也不想有那样的体验了

我的真心：我确实希望能够跟人好好沟通。

障碍：
- 没有观察擅长沟通的人是如何沟通的
- 没有花时间听线上课程，没有看相关的书
- 学了一些技巧，但从没应用过

分析障碍
- 在我的掌控中
- 在我的掌控中
- 在我的掌控中

具体目标：我想要*【与人沟通】*达到*【心里不慌，能顺利地开启和结束对话】*的程度。

具体时间：每天早上8点到8点半看《人性的弱点》这本书，同时做笔记，并且在工作中应用学到的知识。

现在：我想要*【学习与人良好沟通】*，因为*【不会与人沟通给我带来了不好的体验，我再也不想有那样的体验了】*，我的具体目标是*【与人沟通达到心里不慌，能顺利地开启和结束对话的程度】*。我准备*【每天早上8点到8点半】*看《人性的弱点》这本书，同时做笔记，并且在工作中应用学到的知识。

### 我决定放下，果断删掉

过去我以为想要*【学骑马】*

- 逻辑理由：骑马是一种技能，技多不压身
- 逻辑理由：如果哪天车不能用了，可以骑马
- 逻辑理由：新疆马多，学起来很方便
- 情绪理由：看着很酷

我的真心：我觉得能骑马肯定很酷，但我根本用不着。只是因为新疆马多，所以我觉得学也可以。其实我根本就没多想学。我要把*【学骑马】*从我的待办清单上删掉。

现在：我决定放下*【学骑马】*，我已经把它从我的待办清单上删掉了。我删掉它，是因为我发现*【自己其实并不渴望】*。从今以后，我不再为它内耗。我要心无负担地，只做真正想做的事。
