本站（xiangxi.work）由向西运营。本政策旨在向你说明，当您访问本站时，本站如何收集、使用、存储和保护您的相关信息。**本站承诺不出售、不交换访客的个人数据。**

## 一、 本站收集哪些信息及收集方式
1. **访问日志**：当您访问本站时，作为托管服务商的 GitHub 和 CDN 服务商的 Cloudflare 会自动记录您的 IP 地址、访问时间、浏览器类型、访问页面等基础日志信息，用于保障站点的安全与正常运行。
2. **评论信息**：当您在本站发表评论时，评论系统会收集您主动填写的昵称、邮箱地址、网站链接（选填）以及评论内容。
3. **联系信息**：当您通过本站提供的邮箱主动联系本站时，本站会获取您的邮箱地址及您主动发送的通信内容，仅用于与您进行回复交流。
4. **订阅信息**：如果您选择订阅本站的 Newsletter，我们会收集您主动提供的**邮箱地址**。这仅用于向您发送每周的博客更新，以及未来可能向您推送的线上课程等相关动态。您可以随时在邮件底部点击“取消订阅”。
5. **匿名统计数据**：本站使用第三方工具了解访问情况，可能会收集您的设备信息、大致地理位置（国家/城市级别）、页面停留时间、鼠标点击与滚动行为等。

## 二、 第三方服务与数据共享
为了实现博客的各类功能，本站接入了以下第三方服务，它们可能会在提供服务的过程中处理您的数据，并适用其各自的隐私政策：
*   **托管与基础设施**：本站托管于 **GitHub Pages**，并使用 **Cloudflare** 提供加速和静态资源（如样式文件）存储。相关访问数据可能会传输至其位于境外的服务器。
*   **邮件订阅与群发**：本站的 Newsletter 订阅服务由 **Mailchimp** 提供。当您提交订阅表单时，您的邮箱地址及订阅状态将安全存储于 Mailchimp 的服务器中。Mailchimp 可能会使用追踪像素（Tracking Pixels）来统计邮件的打开率和点击率，以便我了解内容的表现。您随时可以取消订阅，取消后您的数据将依据 Mailchimp 的政策被处理。
*   **统计分析**：本站使用 **Google Analytics** 和 **Microsoft Clarity** 了解内容表现。Clarity 会对您的 IP 地址和表单输入进行掩码处理，行为数据通常保留约一年。
*   **广告与推广**：本站使用 **Google AdSense**（已部署代码，正在等待审核）。Google 及其合作伙伴可能使用 Cookie 根据您先前对本站或其他网站的访问记录来投放广告。本站还参与 **阿里联盟** 推广计划，推荐链接可能包含追踪参数或 Cookie，用于识别来自本站的访问与购买。
*   **评论系统**：评论功能由 **IntenseDebate** 提供。您提交的昵称、邮箱和评论内容将存储在其服务器上并公开展示。**请勿在评论中填写密码、身份证号等敏感个人信息。**
*   **支付与外链**：文中的打赏按钮会跳转至 **PayPal**、**爱发电**或**面包多**；商品购买链接可能会跳转至 **面包多**。这些平台作为独立的服务提供者处理您的支付和订单信息，本站不接触、不存储您的任何支付敏感数据。
*   **字体与图标**：本站通过 **Google Fonts** 加载 Roboto 字体，并通过外部 CDN 加载图标字体（如 Font Awesome / Ionicons）。加载时，您的 IP 地址可能会被传输至对应服务商。

## 三、 关于 Cookie 与追踪技术
上述第三方服务（尤其是统计分析、广告推广、评论系统和邮件追踪）可能会在您的浏览器中设置 Cookie 或使用类似追踪技术。您可以通过修改浏览器的隐私设置，拒绝接受或清除 Cookie。但这可能会影响您访问本站部分功能的体验。

## 四、 数据安全与保留期限
本站使用 HTTPS 协议加密传输数据。我们采取合理的措施保护您的信息安全，但请注意，互联网上的数据传输无法保证 100% 绝对安全。第三方服务商（如 Mailchimp、Cloudflare 等）收集的数据，其保留期限由其各自的隐私政策规定。

您有权查询、更正或删除您在本站留下的个人信息（主要是评论和订阅邮箱）。如果您需要行使这些权利，请通过以下方式联系本站：

## 六、 政策更新
本站可能会根据功能调整或法律法规要求更新本隐私政策。重大变更时，我们会在网站内进行公告。建议您定期查看本页面。
